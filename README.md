🎨 8-bit Style Pixel Art Editor (PyQt)
This project is a pixel art editor made with Python and PyQt.
You can choose colors, click the grid, and draw your own pixel art.

Make characters, icons, patterns—anything you like.

🎮 What you can do
Choose canvas size: 16 / 32 / 64

Click to paint each pixel

Pick any color you like

Everything runs in Python

🧠 What you learn
How to build GUI apps

How PyQt works

How to manage a grid of cells

How to detect mouse clicks

How to turn your ideas into real tools

It’s a great way to learn programming by creating something fun.

▶️ How to use
Install Python and PyQt5

Run the script

Choose a canvas size and press “Start!”

Pick a color and click to paint

📦 File overview
MainWindow  
Lets you choose the canvas size

PaintEditor  
The drawing screen

PixelCanvas  
Handles the grid and painting
